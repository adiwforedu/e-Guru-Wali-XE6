Pengaturan Google Drive (Foto Murid)

Otorisasi Drive Diperlukan

  1. Buka Apps Script Editor (dari Spreadsheet: menu Extensions → Apps Script)
  2. Pastikan file appsscript.json sudah berisi scope Drive (lihat file yang disertakan)
  3. Di dropdown fungsi, pilih requestDriveAuth
  4. Klik tombol Run ▶
  5. Setujui SEMUA izin yang muncul di dialog popup (termasuk "See, edit, create and delete all of your Google Drive files")
  6. Kembali ke halaman ini, klik tombol Cek Ulang Otorisasi di bawah

Masukkan ID Folder Google Drive tempat foto murid akan disimpan. Folder harus dibagikan ke akun Google yang sama dengan pemilik Apps Script dengan izin Editor.

Cara mendapatkan ID Folder: buka folder di Drive → salin bagian akhir URL:
drive.google.com/drive/folders/1BxiMVs0XRA5nFMdKvBdBZjgmUUqptlbs
